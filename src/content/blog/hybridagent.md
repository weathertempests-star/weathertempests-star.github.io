助手在解一道複雜問題時，可能先寫出推理，再呼叫工具，讀完結果後又繼續寫。  
文字讓人能追蹤進度，也讓不同工具容易接在一起。  
但如果每個中間步驟都得轉成一個個文字單位，模型就得花時間把原本已在內部運算的資訊重新表達出來。

[Hybrid Reasoning Agents](https://arxiv.org/abs/2610.18861v1) 提出另一種安排：部分內部計算直接以向量延續，需要呼叫工具、留下關鍵檢查點或交付答案時，再回到文字。  
作者稱這套系統為 HybridAgent。  
它嘗試減少的是中間計算的文字化成本，並沒有讓模型跳過運算、憑空得到答案。

## 文字是溝通方式，也有轉換成本

一般語言模型會把內部狀態轉成下一個 token 的機率，再選出 token，作為下一步的輸入。  
token 是模型處理文字的單位，可能是一個字或詞的一部分。  
如此反覆，才形成我們看到的句子。

HybridAgent 多了一種潛在模式，也就是直接使用連續向量的模式。  
模型不必每一步都從詞彙表選字，而是把上一輪的內部表示接回下一輪輸入。  
可以把這理解成保留計算中的工作狀態，而不急著把每一個狀態寫成報告；這只是功能上的比喻，不表示模型具有人的心智活動。

兩種表示不能直接假定相容。  
模型最後一層的輸出，與原本接收文字時使用的輸入表示，可能有不同分布。  
研究因此加入小型轉換模組 HybridLink，學習把內部狀態調整成下一步可使用的輸入。

## 接上工具後，還要記得前面做過什麼

只處理一道題的一段生成，與讓助手多次呼叫工具，是不同的難度。  
工具回傳後，模型必須接著先前的文字與向量狀態繼續工作，不能只剩下最後一段可讀摘要。  
HybridAgent 把這些步驟依順序保存在同一份 KV cache，也就是注意力運算使用的暫存中。

這樣做讓下一輪能接續完整的混合歷程，不必先把向量轉回文字再重新輸入。  
但「保留完整歷程」也意味著暫存仍會成長。  
少寫一些文字，並不自動等於多輪工作所需的記憶體也縮成同樣比例。

訓練同樣要配合改變。  
模型先學會切換格式與轉換模組，再練習接收自己產生的向量，降低訓練時只見過理想輸入、實際執行卻接不上的落差。  
後續強化學習則根據答案、格式與工具使用結果調整行為，學習何時切換；獎勵沒有直接要求它盡量多用潛在模式。

## 品質改善，要看相同條件下的比較

作者以 Qwen3-Base 的四十億、八十億與一百四十億參數版本，測試十一個涵蓋數學、知識與工具搜尋的基準。  
較容易判讀的證據，是同一規模、相近訓練設定下的比較。  
例如一百四十億參數版本在 MATH500 上，HybridAgent 強化學習版為 88.2，文字方法 GRPO 為 87.4、ARPO 為 87.0。

這是一項改善，但幅度不能與跨模型排行榜的平均提升混為一談。  
不同模型可能使用不同資料與系統設計，分數差距未必都由文字與向量混合這個因素造成。  
監督式微調階段的提升也不是每項任務都很大，仍需把架構與完整訓練流程一起評估。

為了確認向量模式確實被使用，作者刻意替換、打亂或縮短其中的向量序列。  
在 MATH500 的一百四十億參數版本中，禁止進入潛在模式後，成績從 88.2 降至 78.8。  
這支持模型依賴該模式完成工作，卻不能證明每一步向量運算都有獨立、可命名的推理意義。

## 文字變少，帳單不一定照比例下降

論文報告生成 token 減少約 35.5% 至 54.7%，推論速度提高約 1.8 至 2.6 倍。  
理解這些結果時，要把可見文字數、實際生成步數與完整任務耗時分開。  
向量步驟仍須讓模型進行一次運算，不能把沒有輸出文字視為沒有成本。

作者的成本估算有把每個文字或向量步驟都算成完整模型前向運算，再加入各自的轉換成本。  
但估算排除了最初讀取提示、隨上下文增長的注意力成本，以及外部工具執行。  
因此，報告的 2.7 至 3.7 倍成本差距，是在指定硬體價格與使用率假設下的生成部分估計，不能直接當成正式服務帳單的節省比例。

## 看得見的紀錄，是否足夠檢查？

模型少寫一些文字，也讓外部檢查者少了一部分線索。  
作者測試保留下來的文字紀錄，發現它們在選定任務中仍能支援錯誤偵測、定位與修正。  
較短的紀錄可能保留了比較密集的關鍵步驟，但這還不是對惡意或欺騙行為的安全保證。

研究也把向量對應到最接近的詞彙，產生方便觀察的文字。  
這種讀法可以提供線索，卻不等於忠實翻譯模型全部的內部計算。  
詞彙位置接近，只是表示上的相似，不能直接當成因果解釋。

目前這份工作仍是預印本，本文未重現實驗。  
它需要調整訓練、生成與暫存管理，並非在既有封閉模型 API 外面加一句提示就能取得的能力。  
HybridAgent 提供了一個值得研究的方向：讓內部計算使用合適的表示，同時留下足以檢查外部行動的紀錄；效率與可監督性，仍需在完整工作流程中共同驗證。
