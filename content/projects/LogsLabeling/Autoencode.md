# AutoEncoder（自編碼器）

> **核心理念**：模型學習重建正常日誌；異常日誌偏離學習模式，重建誤差顯著偏高。

[[Anomaly-Detection|← Stage II 異常偵測總覽]]

---

## 網路架構

```
Encoder（壓縮）：
  [768] → Linear/ReLU/BN → [128]
  [128] → Linear/ReLU/BN → [64]
  [64]  → Linear         → [32]  ← Latent Space（資訊瓶頸）

Decoder（還原）：
  [32]  → Linear/ReLU/BN → [64]
  [64]  → Linear/ReLU/BN → [128]
  [128] → Linear         → [768] ← 重建輸出
```

---

## 異常偵測原理

$$
\text{MSE} = \frac{1}{d} \sum_{i=1}^{d} (x_i - \hat{x}_i)^2
$$

- **正常資料**：符合訓練學到的模式，MSE 低 → 異常分數低
- **異常資料**：偏離學習模式，MSE 高 → 異常分數高

**資訊瓶頸**：32-dim 潛在空間只能編碼「常見」特徵組合，異常的特徵組合難以通過。

---

## 關鍵特性

| 優勢 | 限制 |
|------|------|
| 捕捉複雜非線性模式 | 訓練輪數過多可能過擬合 |
| 語義壓縮，保留關鍵資訊 | 需要 GPU 與訓練時間 |
| 自動學習重要特徵 | 小樣本難以有效學習 |
| 支援 GPU 加速 | 超參數需要調整 |

---

## 對各類攻擊的適用性

| 攻擊類型 | 效果 | 原因 |
|----------|------|------|
| 語義偏離攻擊 | ★★★★★ | 攻擊語義難以被正常模式重建 |
| 複雜多步驟攻擊 | ★★★★☆ | 學習序列語義模式 |
| 全新攻擊類型 | ★★★★☆ | 未知模式重建誤差通常較高 |
| 微小變異攻擊 | ★★★☆☆ | 變異過小可能被成功重建 |

---

## 關鍵超參數

| 參數 | 建議值 | 影響 |
|------|--------|------|
| `AE_LATENT_DIM` | `32` | 太小損失資訊，太大失去瓶頸效果 |
| `AE_EPOCHS` | `50` | 過多可能過擬合正常樣本 |

### 調整策略

| 問題 | 解法 |
|------|------|
| 誤報過多 | 減少 Epochs、增加 Latent Dim |
| 漏報過多 | 增加 Epochs、減少 Latent Dim |
| 訓練不穩定 | 降低 learning rate、增加 BatchNorm |
